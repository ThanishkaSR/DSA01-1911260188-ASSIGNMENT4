## Assignment Tasks

### Task 1 – Class Design Review
Analyzed the given staff payroll classes, identified design deficiencies, and redesigned them using inheritance, encapsulation, and virtual functions.

### Task 2 – University People Hierarchy
Designed a university class hierarchy involving Person, Student, Staff, TeachingAssistant, and ResearchScholar. Implemented multiple inheritance and virtual inheritance to solve the diamond problem.

### Task 3 – Constructors and Destructors
Implemented constructors using initializer lists, member classes, and virtual base classes. Analyzed constructor and destructor execution order.

### Task 4 – Pointers to Derived Classes
Demonstrated virtual functions, virtual destructors, polymorphism, and object slicing using base-class and derived-class pointers.

### Task 5 – Object Pointers and `this`
Implemented object pointers, the `this` pointer, member functions, method chaining, and an array of object pointers.

### Task 6 – Vehicle Rental Fleet Design
Designed a reusable vehicle rental system using an abstract base class and derived classes for different vehicle types. Demonstrated rental operations, return operations, late charges, and extensibility.
